# FatihMH — Multilingual Professional Website

A multilingual professional portfolio presenting technical expertise, digital projects and selected engineering case studies in **Arabic, English and French**.

**Live website:** https://fatihmh.online/

## Project overview

FatihMH is a multi-page professional website built with **WordPress**, hosted on **AWS** using a dedicated **Linux server environment** based on the Red Hat family.

The website brings together a professional profile, technical expertise, case studies, and contact information in three languages.

## What the website demonstrates

- Multilingual content organization and publishing.
- Professional portfolio design and clear navigation.
- Presentation of infrastructure, networking and digital projects.
- Content management and ongoing website maintenance.
